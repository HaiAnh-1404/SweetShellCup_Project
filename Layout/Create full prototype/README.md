# Sweet Shell Cup - Prototype đầy đủ

## 🎨 Tổng quan
Prototype hoàn chỉnh của trang web cửa hàng kem Sweet Shell Cup với 6 trang được kết nối hoàn toàn.

## 📱 Các trang có sẵn

1. **Home** - `/`
2. **Our Story** - `/our-story`
3. **Shop** - `/shop`
4. **Cart** - `/cart`
5. **Feedback** - `/feedback`
6. **Product Detail** - `/detail/1`

## 🚀 Cách sử dụng

### Điều hướng qua Menu:
Click vào các mục trong menu header:
- Home
- Our Story
- Shop
- Cart
- Feedback
- Contact

### Xem chi tiết sản phẩm:
1. Vào trang **Shop**
2. Click vào hình ảnh sản phẩm hoặc icon giỏ hàng
3. Xem chi tiết sản phẩm
4. Click nút **Back** để quay lại Shop
