## 🧭 Navigation

### Menu Navigation (Tất cả trang)
Click vào menu items ở header:

```
┌─────────────────────────────────────┐
│  Home | Our Story | Shop | Cart... │
└─────────────────────────────────────┘
```

- **Home** → Trang chủ
- **Our Story** → Câu chuyện thương hiệu
- **Shop** → Danh sách sản phẩm
- **Cart** → Giỏ hàng
- **Feedback** → Đánh giá khách hàng

### Product Detail Flow
```
Shop → Click vào sản phẩm → Detail → Click "Back" → Shop
```
